# Table 1. The hidden second disease

Two of the eight emergency scenarios contained a *Staphylococcus aureus* endocarditis with a new aortic murmur, behind a septic knee and behind a spondylodiscitis. The primary diagnosis was reached in every consultation. Runs are consultations; a turn is one doctor action, with a budget of twelve.

| | Astra | Fable 5.1 |
|---|---|---|
| **Hidden chart** (the model must ask, examine and order) | | |
| Correct primary diagnosis | 8/8 | 4/4 |
| Heart auscultated | 0/8 | 0/4 |
| Echocardiogram ordered | 0/8 | 0/4 |
| Turns used, septic knee (of 12) | median 6 | 11, 12 |
| Turns used, spondylodiscitis (of 12) | median 10.5 | 13, 13 |
| **Same patients as a written record**, murmur in the text | | |
| Endocarditis considered, echocardiogram advised | 12/12 | 2/2 |
| **Asked directly** whether such a patient needs an echocardiogram | correct rule 4/4 | correct rule 1/1 |

Adaptive clinical intelligence, the fraction of runs in which the examination was completed after the diagnosis was secured, scored as auscultation performed or echocardiography ordered: **0 of 12** (exact 95% confidence interval 0 to 26.5%).

The remaining experiments, about 710 graded answers on some forty-five written rheumatology scenarios, are reported in full, with every scenario, hidden chart, rubric, raw output and transcript, in the repository at https://github.com/drvincentvenus/astra-adaptive-intelligence and in the Supplementary Information.
